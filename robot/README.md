# Robot

Reference robot built on the board – the end-to-end test of hardware, driver and firmware.

## Plan

- Modular LEGO Technic chassis (differential drive, 2 × EV3/NXT large motors) with the board,
  a Raspberry Pi and a 3S battery pack in the case from `enclosure/`.
- Sensors: colour (line following), ultrasonic (obstacles), touch, gyro.
- Example programs in Python using the driver from `driver/`; later ROS 2 node.
- Build instructions with a parts list (LEGO element IDs) and photos.
